# 🌳 Yggdrasil

> Pure Rust-powered autonomous AI IDE powered by free-tier NVIDIA NIM with dynamic model switching (Nemotron, Mistral Large Multimodal, Qwen Coder, DeepSeek R1).

## 🚀 Features
- **Pure Rust GUI**: Ultra-low latency, zero Electron/Webview bloat.
- **Autonomous Multi-Agent Swarm**: Coding, debugging, compilation diagnostics, and deployment orchestration.
- **Dynamic NVIDIA NIM Model Switching**: Switch seamlessly between reasoning, coding, and vision models (`nvidia/nemotron-3.5-lightning-30b-a3b`, `mistralai/mistral-large-4-1t-a52b`, `qwen/qwen2.5-coder-32b-instruct`).
- **Multimodal Support**: Drag-and-drop screenshot UI inspection.
- **Embedded PTY Terminal**: Run local compilers, cargo, and git commands directly.
